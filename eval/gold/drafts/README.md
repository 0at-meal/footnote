## Known limits

- `tieout` verifies values, signs and scale arithmetically and against XBRL. It does not
  verify line *labels* or that the right table was chosen. P0-05b and the owner's table
  confirmation (P0-06) cover those.
- When period headers are misaligned in the HTML, columns are assigned by phrase order
  (marked "assigned by column order" in the period label); the anchor check validates them.
